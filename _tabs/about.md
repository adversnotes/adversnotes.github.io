**Adversary's Notes** es un blog de Threat Intelligence centrado en la infraestructura de adversarios.

Aquí publico análisis de campañas de phishing, servidores C2 y grupos APT, siempre a partir de fuentes públicas y con la metodología de pivoting a la vista, para que cualquiera pueda reproducirla.

Las ideas para cada post surgen en su mayoría a partir de las lecciones y retos planteados en {% include tool-link.html url="https://academy.intel-ops.io/" name="Intel-Ops Academy" %}, y su aplicación a partir de mi propia investigación y análisis.

Las investigaciones se realizan principalmente con la ayuda de las siguientes herramientas:

- {% include tool-link.html url="https://magnify.modat.io/" name="MODAT Magnify" %}
- {% include tool-link.html url="https://www.shodan.io/" name="Shodan" %}
- {% include tool-link.html url="https://search.censys.io/" name="Censys" %}
- {% include tool-link.html url="https://app.validin.com/" name="Validin" %}
- {% include tool-link.html url="https://urlscan.io/" name="urlscan" %}
- {% include tool-link.html url="https://www.virustotal.com/" name="VirusTotal" %}
- {% include tool-link.html url="https://en.fofa.info/" name="FOFA" %}

Cada post incluye los indicadores, su nivel de confianza y las limitaciones del análisis. Todo el contenido es **TLP:CLEAR**.
